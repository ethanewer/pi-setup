# unslop

First-party, skills-only package for this Pi setup. Carries the `unslop` skill,
adapted from [cursor/plugins](https://github.com/cursor/plugins) with the
"Adding soul" section removed and the process reduced to three steps. No
extensions, no tools. Nothing loaded into a running session beyond the skill
description. Nothing to re-vendor.

The skill tells the model to cut AI tells from any writing and to always apply.
See [`skills/unslop/SKILL.md`](skills/unslop/SKILL.md).
