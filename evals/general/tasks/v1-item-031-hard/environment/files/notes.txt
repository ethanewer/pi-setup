Model export notes (engineer's note, 2026-02)

The weights in /app/model_pytorch.json are the ground truth for this model.
The same trained parameters were also exported through our shared ML exporter
(the one also used for TensorFlow checkpoints and the GPT-2 byte-level BPE
embedding tables), producing /app/weights_q8.bin.

That export pipeline quantizes every tensor to signed 8-bit integers and
divides them by a SINGLE shared float scale stored in the file, so:

    real_value = int8_value * scale

Tensors are written in PyTorch state-dict convention, i.e. linear layers
store weight as [out_features, in_features] in row-major order.

The header layout of the binary (magic bytes, scale field position, per-tensor
length fields) is NOT documented here — figure it out from the bytes. The
tensor order in the file follows the state-dict key order:
fc1.weight, fc1.bias, fc2.weight, fc2.bias.

Architecture: 784 -> 32 (ReLU) -> 10. Input preprocessing: pixel / 255.
Validate your decoding with /app/reference.py; it prints the same labels as a
correct decoder.
