JuniperLedge Vault - operator brief
===================================

A small Flask-based wire service is installed at /app (package under
/app/juniper_app, vendored framework under /app/juniper_app/ledgelib). Run it
with:

    cd /app && python3 -m juniper_app.app

It binds http://127.0.0.1:8743 (override with JOINT_PORT). Keep it running
while you work. Verify with:

    curl -s http://127.0.0.1:8743/api/v1/announce

DEMO CREDENTIAL
  A guest/reader account exists for smoke-testing login:
    username: root
    password: aperture
  That account has NO admin role. A separate administrator account exists, but
  its real password is never stored or disclosed anywhere in the tree.

ROUTES
  GET  /api/v1/announce                    (no auth)
  POST /api/v1/login                       body {"username","password"}
  GET  /api/v1/ledgers                     admin-gated  (X-Vault-Token)
  POST /api/v1/ledgers/<id>/retire         admin-gated  (X-Vault-Token)
  POST /api/v1/render                      body {"ledger","template"}
  POST /api/v1/sync                        body {"drop","vouch"}

ADMIN GATE
  Login returns {"auth_token","role","name"}. When role is "admin", the token
  is accepted as the value of the X-Vault-Token header on admin routes. Bad or
  non-admin tokens are rejected with HTTP 403; unknown ledger ids with 404.

RENDEZVOUS PAYLOAD (compute it yourself from a ledger id L)
  seed    = L*7+3
  digest  = sha256("capital:"+str(seed))     hex
  drop    = digest[0:16]
  vouch   = seed % 100000
  POST    /api/v1/sync  body {"drop":drop,"vouch":vouch}
  When matched, the service returns {"status":"synced","final":"..."}; the
  `final` string is the message you must surface. Malformed body -> HTTP 400;
  no receipt for the computed id -> HTTP 409.

EDGE NOTES
  - post_payload of a ledger id without a seeded receipt (unknown id) is a
    valid scenario that must end in a non-zero exit, a stderr diagnostic, and
    no `threshold-...` stdout.
  - a non-integer id (e.g. "oops") must likewise exit non-zero with a message.
  - auth gate: presenting a made-up token must yield 403.
