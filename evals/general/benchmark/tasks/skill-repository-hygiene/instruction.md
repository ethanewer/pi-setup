# Repository hygiene: .gitignore and a clean commit

`/app/repo` is an (empty-history) Git repository that contains a mix of source files
and junk:

```
/app/repo/main.py            # real source
/app/repo/README.md          # real documentation
/app/repo/debug.log          # build junk
/app/repo/temp.tmp           # build junk
/app/repo/cache/output.dat   # generated artifacts
/app/repo/__pycache__/m.pyc  # generated byte-code
```

Your job — repository hygiene:

1. Create `.gitignore` inside `/app/repo` that ignores generated junk:
   - `*.log`
   - `*.tmp`
   - `cache/`
   - `__pycache__/`
2. Stage the repository with `git add -A` and commit **everything that is not ignored**
   with the commit message exactly `hygiene`. The junk files must **not** be committed.
3. Verify after committing: `git status --porcelain` prints nothing (the working tree is
   clean — ignored files are allowed to remain on disk).

The verifier checks: `.gitignore` ignores all four patterns, the commit message is
`hygiene`, `git ls-files` contains exactly `.gitignore`, `main.py`, `README.md` (no
`*.log`/`*.tmp`/`cache/`/`__pycache__` entries), and `git status --porcelain` is empty.
