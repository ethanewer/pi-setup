# Building plotsmith

`./configure` defaults to `--with-x`: that build compiles `gui/xfront.c`,
links the X11 library shim under `compat/`, and produces `plotsmith-x`.

For hosts with no display stack the supported configuration is:

    ./configure --without-x
    make

which compiles only the non-graphical engine (`core/`) and produces the
single binary `plotsmith`. The X11 frontend sources and the compat shim are
excluded from that build, and the resulting binary references no X11 library.

Headless usage:

    plotsmith <job.txt> <out.pbm>

Job verbs (one per line; blank lines and `#` comments are skipped; a line
whose verb is unknown or whose argument count/types are wrong is skipped):

    dot X Y
    hline X1 X2 Y
    vline X Y1 Y2
    rect X Y W H      # outline; rows Y and Y+H-1, cols X and X+W-1; W,H must be > 0
    fill X Y W H      # solid; W,H must be > 0
    clear             # wipes the canvas

The canvas is 24x16, one bit per pixel (0 = paper, 1 = ink). Every primitive
clips: pixel coordinates outside the canvas are ignored. `hline`/`vline`
accept endpoints in either order and are inclusive. Output is plain ASCII
PBM ("P1"), 0 = paper, 1 = ink, rows space-separated.
