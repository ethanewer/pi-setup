# Integer list probe

`/app/numbers.txt` contains a small list of integers, one per line. Some lines
may be blank. Read the file and compute:

1. `count` — the number of integers in the file (ignore blank lines).
2. `sum` — their arithmetic sum.

Write these to `/app/answer.json`:

```json
{
  "count": 5,
  "sum": 14
}
```

Compute the values from the actual file contents.
